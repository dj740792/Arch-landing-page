# Oasis.

> We design atmospheres, not just buildings.

Oasis is a high-end architectural studio platform crafted for immersive, spatial storytelling. Built with a focus on material honesty, quiet architecture, and sculptural geometry, this web experience communicates modern design ethos through smooth motion, refined typography, and full-screen visual showcases.

---

## Brand Vision

In a world overwhelmed by noise, Oasis focuses on the power of quiet architecture. Raw textures, sun-washed surfaces, and sculptural forms create calm environments that feel thoughtful, elevated, and enduring. This site acts as an interactive showcase for selected architectural works, music video direction, documentaries, and spatial design projects.

---

## Tech Stack & Libraries

* Framework: Next.js (App Router, Server & Client Components)
* Styling: Tailwind CSS
* Animations: Framer Motion
* Smooth Scroll: Lenis Scroll
* Icons: Lucide React
* Typography: next/font (Raleway, Cormorant Garamond, Aboreto, Fjalla One)

## Getting Started

### Prerequisites

Ensure you have Node.js 18+ installed on your system.

### Installation

1. Clone the repository:
   git clone https://github.com/dj740792/Oasis-website
   cd oasis-architecture

2. Install dependencies:
   npm install
   # or
   yarn install
   # or
   pnpm install
   # or
   bun install

3. Run the development server:
   npm run dev
   # or
   yarn dev
   # or
   pnpm dev
   # or
   bun dev

4. View in browser:
   Open http://localhost:3000 to see the application running locally.
